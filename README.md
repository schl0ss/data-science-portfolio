# Georgia Tech Data Science Portfolio

Selected data science and analytics projects from Georgia Tech's MS Analytics program. This repo is intended as inspection-ready proof of ML, NLP, data visualization, modeling judgment, and analytical communication.

## Reviewer Path

If you have five minutes:

1. Read the NLP practicum summary.
2. Open the Moneyball code and report links.
3. Skim College Seeker for visualization and team leadership evidence.

If you are evaluating AI engineer fit, look for:

- **Modeling judgment**: problem framing, feature choices, model comparison, and validation.
- **Data fluency**: messy real-world inputs, analysis pipelines, visualization, and interpretation.
- **Communication**: technical reports, stakeholder-ready artifacts, and clear decision framing.

## Case Studies

### 1. NLP Bullying Classification

Created in Spring 2023 while working with Pinwheel.

Problem: classify instances of bullying in kids' text conversations using natural language processing.

Methods: Python, Hugging Face, transformer-based NLP, and model evaluation for unstructured text.

Evidence: the full technical report shows the modeling approach, implementation choices, and analysis.

AI engineering relevance: demonstrates applied NLP, sensitive-domain judgment, and the ability to turn ambiguous language data into a model-backed decision surface.

Artifacts:

- [Full Report PDF](https://drive.google.com/file/d/1_U6eHDzB4FMVnJPEG_GWk19pIkc634Ne/view?usp=share_link)

### 2. NBA Moneyball: Predicting Player Salary

Solo project created in Fall 2022 for Georgia Tech's Data Mining and Statistical Learning course, ISYE 7406.

Problem: predict NBA player salary from player and performance data.

Methods: R, data engineering, feature construction, statistical learning, and model comparison across multiple model families.

Evidence: the code, full report, and presentation show the data pipeline, modeling process, and interpretation.

AI engineering relevance: demonstrates end-to-end predictive modeling, model selection, quantitative reasoning, and clear communication of results.

Artifacts:

- [moneyball.r](https://github.com/schl0ss/data-science-portfolio/blob/b3be8f9dd08fcff9d713d5a46378f0122d5507cc/moneyball.r)
- [Full Report PDF](https://drive.google.com/file/d/1UDpnMBsEjJUNADsGKXk7pUEwyUegQUGX/view?usp=share_link)
- [Presentation PDF](https://drive.google.com/file/d/1iUzgHEkkYVbu3iYMrmXyxT5WgbGIhkfn/view?usp=share_link)

### 3. College Seeker: Explore The University Universe

Group project created in Spring 2021 for Georgia Tech's Data and Visual Analytics course, CSE 6242.

Problem: help users explore universities through an interactive visual analytics experience.

Methods: data visualization, product framing, team coordination, report writing, poster design, and agile project management.

Evidence: the deployed site, poster, and report show the interactive artifact and the reasoning behind the design.

AI engineering relevance: demonstrates user-facing data product judgment, visualization communication, and technical leadership in a distributed team.

Artifacts:

- [CollegeSeeker.net](https://collegeseeker.net)
- [Poster PDF](https://drive.google.com/file/d/1Mph1EdMSWuE4Q94eF9R4NvPSXE7Gp3CN/view?usp=share_link)
